# Open-source surface

Repository: **https://github.com/winsznx/signet**
Branch: `build/signet-autonomous` (the repository's default branch)
Visibility: **public**, verified by unauthenticated fetch of the raw README

Flare requires that contracts and the core backend/off-chain logic essential to proving the Flare
integration be open source. This maps every submission claim to the public files that prove it.

**No submission-critical claim depends on code absent from this repository.** 217 tracked files, no
private submodules, no vendored binaries, and no build step that reaches for anything unpublished.

## What is pinned rather than ours

Eleven upstream sources are vendored under [`upstream/`](../../upstream/) and content-hashed in
[`docs/source-lock.json`](../source-lock.json): FAssets, FDC, the FCC extension scaffold, tee-proxy,
fce-sign, the Flare periphery packages, the developer hub, the C-chain indexer, OpenZeppelin and
forge-std. `make bootstrap` refetches all of them and `make verify` fails on a content-hash mismatch.

None is modified. Modifying pinned upstream requires an ADR and a source-lock update, and no such ADR
exists.

## What is deliberately not in the repository

| | |
|---|---|
| testnet keys | generated locally under `.runtime/secrets/`, gitignored, mode 600, never printed |
| the shared FCC indexer credential | written only to a gitignored local proxy config, verified with `git check-ignore` before writing. **0 tracked files contain it** |
| the Cosmica typeface | not licensed for redistribution; the page falls through to DM Sans |

Verified by `make scan`: 217 tracked files scanned, no key material. A full-history scan for PEM
blocks and hex private keys returns only the secret scanner's own synthetic fixtures.

## Reproducing the whole thing

```bash
git clone https://github.com/winsznx/signet
cd signet
pnpm install --frozen-lockfile
bash scripts/install-go.sh
make verify     # every gate
make judge      # independent verification, no wallet, no funds, no secrets
make doctor     # read-only diagnosis of the deployed FCC surface
```
